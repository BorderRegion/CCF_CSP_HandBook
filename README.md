# CCF CSP 考场手册

作者：朝汐

《CCF CSP 考场手册》是一份面向 CCF CSP 认证备考和临场检索的开源资料。它比较适合基础薄弱、算法水平一般的同学，用来在 CCF CSP 中争取拿到 300 分左右，重点是帮助读者尽量稳定地拿下前三题和可拿的部分分。

这本手册不是从完整算法竞赛知识体系出发，而是从考试现场最容易遇到的问题出发：题面该怎么读，数据范围该怎么判断，应该先写哪种模板，遇到难题时怎样拿到尽可能稳定的部分分。

## 这本书解决什么问题

第一个问题是题型判断。很多 CSP 题目并不是看一眼就能知道该写什么，尤其是 B、C、D/E 题，题面里经常混着模拟、数据结构、图论、动态规划、贪心和字符串处理。手册把题面信号、数据范围和操作模式拆开，尽量让读题之后能快速落到某个模板入口。

第二个问题是基础细节。C++ 的整数除法、向上取整、负数取模、下标边界、`size()` 倒序循环、初始化和溢出，都是 CSP 里很容易扣分的地方。手册把这些内容放在基础部分和易错清单里，不只写结论，也给出可直接套用的写法。

第三个问题是考场检索。复习资料如果只能从头读到尾，临场价值就会下降。所以这本书前面放了极速索引和判断树，后面放模板库、易错点总表和真题索引，目的是让你能按“我现在卡在哪一步”反向查。

第四个问题是部分分策略。D/E 题不一定每次都能完整做出来，但很多题可以先写暴力、小数据、特殊结构或简化状态。手册专门整理了部分分入口，帮助把时间用在更确定的得分点上。

## 怎么使用

复习时可以先读前几章，建立一个基本的题型判断框架。之后不要急着背完整模板，而是拿历年题反查：这题的题面信号是什么，数据范围卡掉了哪些做法，最后应该落到哪一个模板。

临场时建议先看极速索引，再根据题号和数据范围决定策略。A 题优先保证格式和边界；B 题优先判断前缀和、差分、哈希、二分、图论或 DP；C 题优先拆状态、解析规则和事件流程；D/E 题先判断能不能拿小数据、特殊结构或暴力部分分。

打印时可以重点标记三类内容：第 2 章极速索引、第 9 章模板库、第 10 章易错点总表。这三块是最适合考前和临场反复翻的部分。

## 编译方式

本项目使用 `ctexbook` 和 XeLaTeX 编译。

```bash
latexmk -xelatex -interaction=nonstopmode -halt-on-error CCF_CSP_HandBook.tex
```

如果本机没有中文 LaTeX 环境，可以直接下载仓库中的 PDF。

## 说明

注意，这不是一本官方教材，我也无法保证内部内容全然正确，也显然这本书不能带到考场就帮你拿到高分。它是一份把 CSP 常见判断过程、模板入口和易错点放在一起的检索手册，是帮助薄弱的人争取前三题分数的指南。

如果你已经有一定 C++ 基础，它可以帮助你把复习内容组织得更清楚；如果你刚开始准备 CSP，它也可以当作路线图，先知道每类题通常在考什么，再逐步补算法和代码能力。
