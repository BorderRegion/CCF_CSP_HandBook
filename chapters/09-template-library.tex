\section{T101 一维前缀和}\label{sec:09-3}\label{tpl:101}

\subsection{适用场景}

\begin{itemize}
  \item 数组不修改。
  \item 多次查询 $[l,r]$ 的和。
  \item 需要快速得到一段累计值。
\end{itemize}

\subsection{模板}

\begin{lstlisting}
int n, q;
cin >> n >> q;
vector<long long> pre(n + 1, 0);

for (int i = 1; i <= n; i++) {
    long long x;
    cin >> x;
    pre[i] = pre[i - 1] + x;
}

while (q--) {
    int l, r;
    cin >> l >> r;
    cout << pre[r] - pre[l - 1] << '\n';
}
\end{lstlisting}

\subsection{易错点}

\begin{itemize}
  \item 模板默认下标从 1 开始。
  \item \Code{pre[0]} 是 0。
  \item 求和用 \Code{long long}。
  \item 如果有修改，普通前缀和不适用。
\end{itemize}

\section{T102 二维前缀和}\label{sec:09-4}\label{tpl:102}

\subsection{适用场景}

多次查询子矩阵和。

\begin{lstlisting}
int n, m, q;
cin >> n >> m >> q;
vector<vector<long long>> pre(n + 1, vector<long long>(m + 1, 0));

for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        long long x;
        cin >> x;
        pre[i][j] = pre[i - 1][j] + pre[i][j - 1]
                  - pre[i - 1][j - 1] + x;
    }
}

while (q--) {
    int x1, y1, x2, y2;
    cin >> x1 >> y1 >> x2 >> y2;
    long long ans = pre[x2][y2] - pre[x1 - 1][y2]
                  - pre[x2][y1 - 1] + pre[x1 - 1][y1 - 1];
    cout << ans << '\n';
}
\end{lstlisting}

\subsection{易错点}

\begin{itemize}
  \item 四项公式不要写反。
  \item 默认坐标从 1 开始。
  \item 子矩阵端点是否保证 $x1 \le x2, y1 \le y2$。
\end{itemize}

\section{T103 一维差分}\label{sec:09-5}\label{tpl:103}

本例初始数组全为 0。若有初值 a[1..n]，先令 diff[i]=a[i]-a[i-1]（a[0]=0），再处理修改。

\subsection{适用场景}

多次区间加，最后统一输出每个位置的值。

\begin{lstlisting}
int n, q;
cin >> n >> q;
vector<long long> diff(n + 2, 0);

while (q--) {
    int l, r;
    long long v;
    cin >> l >> r >> v;
    diff[l] += v;
    diff[r + 1] -= v;
}

long long cur = 0;
for (int i = 1; i <= n; i++) {
    cur += diff[i];
    cout << cur << '\n';
}
\end{lstlisting}

\subsection{易错点}

\begin{itemize}
  \item 数组开到 \Code{n+2}。
  \item 如果修改后立刻查询区间和，普通差分不够。
  \item 修改值用 \Code{long long}。
\end{itemize}

\section{T104 二维差分}\label{sec:09-6}\label{tpl:104}

本例初始矩阵全为 0。若有初值，重建后的增量应加回原矩阵；最终输出 diff[i][j] 或原值加增量。

\subsection{适用场景}

多次对子矩形加值，最后输出整个矩阵。

\begin{lstlisting}
int n, m, q;
cin >> n >> m >> q;
vector<vector<long long>> diff(n + 2, vector<long long>(m + 2, 0));

while (q--) {
    int x1, y1, x2, y2;
    long long v;
    cin >> x1 >> y1 >> x2 >> y2 >> v;
    diff[x1][y1] += v;
    diff[x2 + 1][y1] -= v;
    diff[x1][y2 + 1] -= v;
    diff[x2 + 1][y2 + 1] += v;
}

for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        diff[i][j] += diff[i - 1][j] + diff[i][j - 1]
                    - diff[i - 1][j - 1];
    }
}
\end{lstlisting}

\section{T105 排序自定义比较器}\label{sec:09-7}\label{tpl:105}

\subsection{适用场景}

多关键字排序、排名、优先级排序。

\begin{lstlisting}
struct Node {
    int id;
    int score;
    int time;
};

sort(a.begin(), a.end(), [](const Node& x, const Node& y) {
    if (x.score != y.score) return x.score > y.score;

  \item 需要保持原顺序时用 \Code{stable\_sort}。
\end{itemize}

\section{T107 二分答案}\label{sec:09-9}\label{tpl:107}

\subsection{适用场景}

\begin{itemize}
  \item 求最小可行值。
  \item 求最大可行值。
  \item 给定答案 $mid$ 能判断是否可行。
  \item 可行性具有单调性。
\end{itemize}

\subsection{最小可行值}

\begin{lstlisting}
bool check(long long mid) {
    // return true if mid is feasible
}

long long l = 0, r = 1000000000000000000LL;
while (l < r) {
    long long mid = l + (r - l) / 2;
    if (check(mid)) r = mid;
    else l = mid + 1;
}
cout << l << '\n';
\end{lstlisting}

\subsection{最大可行值}

\begin{lstlisting}
long long l = 0, r = 1000000000000000000LL;
while (l < r) {
    long long mid = l + (r - l + 1) / 2;
    if (check(mid)) l = mid;
    else r = mid - 1;
}
cout << l << '\n';
\end{lstlisting}

\Warn{二分答案必须有单调性。}最小可行值模板要求初始右端点可行，最大可行值模板要求初始左端点可行；若不能保证，应先判无解。范围按题目推导，不能把 $10^{18}$ 当成通用答案上界。\Code{check} 必须自行实现；上下界差和中点运算也不能溢出。

\section{T108 双指针}\label{sec:09-10}\label{tpl:108}

窗口版求非负数组中“和不超过 limit”的最长连续段，要求 limit 不小于 0；两数和排序后原下标会丢失。

\subsection{排序后找两数和}

\begin{lstlisting}
sort(a.begin(), a.end());
int l = 0, r = n - 1;
bool ok = false;

while (l < r) {
    long long sum = 1LL * a[l] + a[r];
    if (sum == target) {
        ok = true;
        break;
    } else if (sum < target) {
        l++;
    } else {
        r--;
    }
}
\end{lstlisting}

\subsection{非负数组滑动窗口}

\begin{lstlisting}
int l = 0;
long long sum = 0;
int best = 0;

for (int r = 0; r < n; r++) {
    sum += a[r];
    while (sum > limit && l <= r) {
        sum -= a[l];
        l++;
    }
    best = max(best, r - l + 1);
}
\end{lstlisting}

\Warn{滑动窗口通常要求元素非负或条件具有单调性。}

\section{T111 矩阵重塑与乘法顺序}\label{sec:09-13}\label{tpl:111}
\textbf{重塑：}按行展开，旧位置 $(i,j)$ 的线性编号 $k=i\cdot m+j$，重塑为 $r\times c$ 后位于 $(k/c,k\bmod c)$。要求 $nm=rc$，下标从 0 开始。
\begin{lstlisting}
vector<vector<long long>> b(r, vector<long long>(c));
for (int i = 0; i < n; i++)
    for (int j = 0; j < m; j++) {
        long long k = 1LL * i * m + j;
        b[k / c][k % c] = a[i][j];
    }
\end{lstlisting}
\textbf{乘法：}$A$ 为 $n\times d$，$B$ 为 $d\times m$，$C_{ij}=\sum_k A_{ik}B_{kj}$，复杂度 $O(ndm)$。
\begin{lstlisting}
vector<vector<long long>> C(n, vector<long long>(m, 0));
for (int i = 0; i < n; i++)
    for (int k = 0; k < d; k++)
        for (int j = 0; j < m; j++)
            C[i][j] += A[i][k] * B[k][j];
\end{lstlisting}
若 $Q,K,V$ 都是 $n\times d$ 且 $d\ll n$，计算 $(QK^T)V$ 可改成 $Q(K^TV)$，由 $O(n^2d)$ 降至 $O(nd^2)$，避免构造 $n\times n$ 中间矩阵。只能在数学运算允许结合时换序；非线性函数、截断取整不能任意移走。浮点换序可能改变舍入误差。逐行权重乘法必须按原公式位置处理。

\section{T112 稀疏向量点积}\label{sec:09-14}\label{tpl:112}
两个向量仅存非零项，按下标严格升序且各自下标不重复。相同下标的值相乘后相加，复杂度 $O(a+b)$。
\begin{lstlisting}
long long sparseDot(const vector<pair<int,long long>>& a,
                    const vector<pair<int,long long>>& b) {
    size_t i = 0, j = 0;
    long long ans = 0;
    while (i < a.size() && j < b.size()) {
        if (a[i].first < b[j].first) i++;
        else if (a[i].first > b[j].first) j++;
        else {
            ans += a[i].second * b[j].second;
            i++; j++;
        }
    }
    return ans;
}
\end{lstlisting}
若输入无序先排序；若同一下标可重复先合并。乘积与总和均须在 long long 范围内。


\section{T113 有限状态映射与倍增}\label{tpl:113}
若每个状态有唯一后继 next[v]，重复 k 次不必逐步模拟。令 up[b][v] 表示执行 $2^b$ 次后的状态，由两个 $2^{b-1}$ 次复合得到。适合字符替换、指针跳转；要求所有后继在 0 到 V-1，未指定的映射按题意初始化。
\begin{lstlisting}
struct JumpTable {
    vector<vector<int>> up;
    explicit JumpTable(const vector<int>& next) {
        int V = (int)next.size();
        up.assign(64, vector<int>(V));
        up[0] = next;
        for (int b = 1; b < 64; b++)
            for (int v = 0; v < V; v++)
                up[b][v] = up[b-1][up[b-1][v]];
    }
    int jump(int v, unsigned long long k) const {
        for (int b = 0; b < 64; b++)
            if ((k >> b) & 1ULL) v = up[b][v];
        return v;
    }
};
\end{lstlisting}
预处理时间、空间 $O(V\log K)$，单次跳转 $O(\log K)$，此处为无符号 64 位 k 留足 64 层。若映射在有限集合上是单射，则每个连通分量是环，也可按各自环长取模；不能随意用固定数 26 或 63 代替环长。每个查询应从题目指定的初态出发。

值域很小且求逆映射时，还可枚举全部输入 x，算出 y=F(x)，记录 inverse[y]=x；仅在 F 确实单射时才有唯一逆。
\section{T201 网格 BFS}\label{sec:09-15}\label{tpl:201}

默认输入合法的 0 下标坐标，起点终点均可通行，井号为障碍；不可达输出 -1。若题目允许阻塞起点，应先判定。

\subsection{适用场景}

迷宫、最短步数、每一步代价相同。

\begin{lstlisting}
int n, m;
cin >> n >> m;
vector<string> g(n);
for (int i = 0; i < n; i++) cin >> g[i];

\section{T203 并查集}\label{sec:09-17}\label{tpl:203}

\begin{lstlisting}
struct DSU {
    vector<int> parent, sz;

    DSU(int n) {
        parent.resize(n + 1);
        sz.assign(n + 1, 1);
        for (int i = 1; i <= n; i++) parent[i] = i;
    }

    int find(int x) {
        if (parent[x] == x) return x;
        return parent[x] = find(parent[x]);
    }

    bool unite(int a, int b) {
        int ra = find(a);
        int rb = find(b);
        if (ra == rb) return false;
        if (sz[ra] < sz[rb]) swap(ra, rb);
        parent[rb] = ra;
        sz[ra] += sz[rb];
        return true;
    }

    bool same(int a, int b) {
        return find(a) == find(b);
    }
};
\end{lstlisting}

\subsection{适用场景}

\section{T208 LCA 倍增}\label{sec:09-22}\label{tpl:208}

先建好 n 个点的无向树，根为 1，根的父亲为自身。深链可能导致递归爆栈；需要无递归遍历时见 \Tref{209}。

\subsection{适用场景}

\begin{lstlisting}
int LOG; // compute from n before allocating up
vector<vector<int>> up;
vector<int> depth;
vector<vector<int>> g;

void dfsLca(int u, int p) {
    up[0][u] = p;
    for (int k = 1; k < LOG; k++) {
        up[k][u] = up[k - 1][up[k - 1][u]];
    }
    for (int v : g[u]) {
        if (v == p) continue;
        depth[v] = depth[u] + 1;
        dfsLca(v, u);
    }
}

int lca(int a, int b) {
    if (depth[a] < depth[b]) swap(a, b);
    int diff = depth[a] - depth[b];
    for (int k = 0; k < LOG; k++) {
        if (diff & (1 << k)) a = up[k][a];
    }
    if (a == b) return a;
    for (int k = LOG - 1; k >= 0; k--) {
        if (up[k][a] != up[k][b]) {
            a = up[k][a];
            b = up[k][b];
        }
    }
    return up[0][a];
}
\end{lstlisting}

\section{T401 树状数组}\label{sec:09-27}\label{tpl:401}

struct BIT {
    int n;
    vector<long long> tree;

    BIT(int n) : n(n), tree(n + 1, 0) {}

    void add(int idx, long long val) {
        assert(1 <= idx && idx <= n); // idx=0 would never advance
        for (; idx <= n; idx += idx & -idx) {
            tree[idx] += val;
        }
    }

    long long sumPrefix(int idx) {
        assert(0 <= idx && idx <= n);
        long long res = 0;
        for (; idx > 0; idx -= idx & -idx) {
            res += tree[idx];
        }
        return res;
    }

    long long rangeSum(int l, int r) {
        return sumPrefix(r) - sumPrefix(l - 1);
    }
};

\section{T402 线段树}\label{sec:09-28}\label{tpl:402}

\subsection{适用场景}

\begin{lstlisting}
struct SegTree {
    int n;
    vector<long long> tree, lazy;

    SegTree(int n) : n(n), tree(4 * n + 4), lazy(4 * n + 4) {}

    void apply(int node, int l, int r, long long val) {
        tree[node] += val * (r - l + 1);
        lazy[node] += val;
    }

    void push(int node, int l, int r) {
        if (lazy[node] == 0 || l == r) return;
        int mid = (l + r) / 2;
        apply(node * 2, l, mid, lazy[node]);
        apply(node * 2 + 1, mid + 1, r, lazy[node]);
        lazy[node] = 0;
    }

    void rangeAdd(int node, int l, int r, int ql, int qr, long long val) {
        if (ql <= l && r <= qr) {
            apply(node, l, r, val);
            return;
        }
        push(node, l, r);
        int mid = (l + r) / 2;
        if (ql <= mid) rangeAdd(node * 2, l, mid, ql, qr, val);
        if (qr > mid) rangeAdd(node * 2 + 1, mid + 1, r, ql, qr, val);
        tree[node] = tree[node * 2] + tree[node * 2 + 1];
    }

    long long query(int node, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr) return tree[node];
        push(node, l, r);
        int mid = (l + r) / 2;
        long long res = 0;
        if (ql <= mid) res += query(node * 2, l, mid, ql, qr);
        if (qr > mid) res += query(node * 2 + 1, mid + 1, r, ql, qr);
        return res;
    }
};
\end{lstlisting}

struct RangeMax {
    int n;
    vector<long long> t;
    RangeMax(const vector<long long>& a) : n((int)a.size()), t(2*n) {
        assert(n > 0);
        copy(a.begin(), a.end(), t.begin() + n);
        for (int i = n - 1; i > 0; i--)
            t[i] = max(t[i*2], t[i*2+1]);

    long long query(int l, int r) const {
        assert(0 <= l && l <= r && r < n);
        long long ans = LLONG_MIN;
        for (l += n, r += n + 1; l < r; l /= 2, r /= 2) {
            if (l & 1) ans = max(ans, t[l++]);
            if (r & 1) ans = max(ans, t[--r]);
        }
        return ans;
    }
};

}

int countMatch(const string& text, const string& p) {
    if (p.empty()) return (int)text.size() + 1; // empty pattern: all gaps
    vector<int> pi = prefixFunction(p);
    int j = 0, cnt = 0;
    for (char c : text) {
        while (j > 0 && c != p[j]) j = pi[j - 1];
        if (c == p[j]) j++;
        if (j == (int)p.size()) {
            cnt++;
            j = pi[j - 1];
        }
    }
    return cnt;
}
\end{lstlisting}

\section{T503 Trie}\label{sec:09-34}\label{tpl:503}

find 查询完整单词。前缀查询需沿 child 走完后返回 true，不能要求末节点 end=true；本版不支持重复次数统计。

\begin{lstlisting}
struct Trie {
    struct Node {
        int child[26];
        bool end = false;
        Node() {
            memset(child, -1, sizeof child);
        }
    };

    vector<Node> tr;

    Trie() {
        tr.push_back(Node());
    }

    void insert(const string& s) {
        int u = 0;
        for (char c : s) {
            int x = c - 'a';
            if (tr[u].child[x] == -1) {
                tr[u].child[x] = (int)tr.size();
                tr.push_back(Node());
            }
            u = tr[u].child[x];
        }
        tr[u].end = true;
    }

    bool find(const string& s) {
        int u = 0;
        for (char c : s) {
            int x = c - 'a';
            if (tr[u].child[x] == -1) return false;
            u = tr[u].child[x];
        }
        return tr[u].end;
    }
};

        if (x % p != 0) continue;
        int cnt = 0;

        for (long long j = 1LL*p*p; j <= N; j += p)
            prime[j] = false;
    }
    return prime;
}

\section{T604 懒删除优先队列}\label{sec:09-44}\label{tpl:604}

\subsection{适用场景}

\begin{lstlisting}
struct Task {
    int priority;
    int id;
};

struct Cmp {
    bool operator()(const Task& a, const Task& b) const {
        if (a.priority != b.priority) return a.priority < b.priority;
        return a.id > b.id;
    }
};

priority_queue<Task, vector<Task>, Cmp> pq;
map<int, int> currentPriority;

void addOrUpdate(int id, int priority) {
    currentPriority[id] = priority;
    pq.push({priority, id});
}

void removeTask(int id) {
    currentPriority.erase(id);
}

Task getTop() {
    while (!pq.empty()) {
        Task t = pq.top();
        if (currentPriority.count(t.id) &&
            currentPriority[t.id] == t.priority) {
            return t;
        }
        pq.pop();
    }
    return {-1, -1};
}
\end{lstlisting}

\subsection{易错点}

\begin{itemize}
  \item 每次取堆顶前都要清理过期元素。
  \item 更新元素时直接压入新值，不删除旧值。
  \item 判断有效性必须和当前状态表一致。
\end{itemize}

\Code{getTop} 只查看，不消费任务。执行后应调用 \Code{removeTask(t.id)}，下次查询才会清理已执行的堆项；不能只 \Code{pq.pop()} 却保留当前状态表。示例空结果为 id=-1，要求有效编号非负。堆按累计更新数 Q 增长，空间可达 $O(Q)$；仅优先级和编号参与状态校验，若还要区分生命周期须加版本号。

\section{T610 整数四则表达式解析}\label{sec:09-50}\label{tpl:610}
递归下降：expression 处理加减，term 处理乘除，factor 处理整数、括号和一元正负号。要求输入语法合法、整数字面量与全部中间结果可放 long long、除数非零，除法按 C++ 向零截断；不是浮点、幂运算、逻辑式或化学式解析器。深层括号仍有递归栈风险。
\begin{lstlisting}
struct Parser {
    string s;
    size_t p = 0;
    explicit Parser(string text) : s(move(text)) {}
    void skip() {
        while (p < s.size() && isspace((unsigned char)s[p])) p++;
    }
    long long factor() {
        skip();
        if (s[p] == '+' || s[p] == '-') {
            char op = s[p++];
            long long x = factor();
            return op == '-' ? -x : x;
        }
        if (s[p] == '(') {
            p++;
            long long x = expression();
            skip();
            p++; // consume ')' in valid input
            return x;
        }
        long long x = 0;
        while (p < s.size() && isdigit((unsigned char)s[p]))
            x = x * 10 + (s[p++] - '0');
        return x;
    }
    long long term() {
        long long x = factor();
        while (true) {
            skip();
            if (p == s.size() || (s[p] != '*' && s[p] != '/')) return x;
            char op = s[p++];
            long long y = factor();
            x = (op == '*') ? x * y : x / y;
        }
    }
    long long expression() {
        long long x = term();
        while (true) {
            skip();
            if (p == s.size() || (s[p] != '+' && s[p] != '-')) return x;
            char op = s[p++];
            long long y = term();
            x = (op == '+') ? x + y : x - y;
        }
    }
};
// Parser parser(line); cout << parser.expression() << '\n';
\end{lstlisting}
二十四点等题若用 x 表示乘号，读入后先替换为 *。模意义下除法不能直接用本模板。梯度求解需传播函数值和导数；化学方程式配平还需要建立方程并求解，本模板仅提供算术解析基础。
